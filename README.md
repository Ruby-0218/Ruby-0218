## Featured Data Science Projects

I specialize in building end-to-end data products, from data engineering and machine learning to interactive web deployments. Here are my recent major projects:

### [Corporate Greenwashing Analyzer]
**An ESG analytics platform detecting greenwashing patterns via Machine Learning.**
* **Overview:** Designed an interactive dashboard to investigate the paradox between rising corporate ESG scores and actual carbon emissions (Scope 1-3). 
* **Tech Stack:** Python, Streamlit, Scikit-Learn (Random Forest), Plotly, YFinance API.
* **Highlights:** Engineered a custom *ESG Credibility Index* and deployed an ML classifier to identify key predictors of corporate greenwashing across the Energy, Utilities, and Industrials sectors.
* **[Live Dashboard](https://corporate-greenwashing-analyzer-any9e9omuwmcpbudtvm6h6.streamlit.app/?page=Overview)**

### [Pricing Market Sentiment]
**An NLP-driven dashboard analyzing retail investor sentiment vs. stock performance.**
* **Overview:** Built a dynamic visualization tool to answer: *Are high-growth technology stocks more sensitive to retail investor sentiment than traditional value stocks?*
* **Tech Stack:** Python, Streamlit, Pandas, NLP (Sentiment Analysis).
* **Highlights:** Extracted and processed massive historical discussion datasets from Reddit's `r/wallstreetbets` to compare stock returns, volatility, and semantic sentiment polarity.
* **[Live Dashboard](https://qmss-g5063-final-project-gpjqh8qnnvlb6j24csauf2.streamlit.app/)**
